# Requirements: 파워점핑 — 신나는 줄넘기 미션

**Defined:** 2026-10-22 (Milestone v2.0 3D 블루마블 재구축)
**Core Value:** 주사위 → 이동 → 도착 칸 줄넘기 퀘스트 → 성공하면 성공 애니메이션과 별, 이 핵심 루프가 아이들에게 신나고 매끄럽게 돌아가는 것. 그리고 강사가 미션을 자유롭게 관리(추가/수정/삭제)할 수 있는 것.

> v1.0 요구사항(편집기 MISSION-01~07, 이벤트 EVENT-01~05, 저장 DATA-01~04, 설정 SETUP-01~06 등)은 `.planning/milestones/v1.0-REQUIREMENTS.md`에 보관. 그중 편집기·저장·개인전/팀전 설정은 v2.0에서도 그대로 유지되며(검증 완료), 아래는 v2.0에서 새로 만들거나 바뀌는 것만 다룬다.

## v2.0 Requirements

### 데이터 보존 (DATA)

- [x] **DATA-05**: 기존(v1) 기기에 저장된 미션·이벤트가 v2 업데이트 후에도 하나도 사라지지 않고 그대로 유지된다
- [x] **DATA-06**: 예전에 내보낸 v1 백업 파일(JSON)을 v2에서도 그대로 가져올 수 있다
- [x] **DATA-07**: 강사 설정은 미션·이벤트와 별도로 기기에 자동 저장되어 새로고침 후에도 유지되며, 백업 파일(JSON)에는 포함되지 않는다

### 강사 설정 (CFG)

- [x] **CFG-01**: 강사는 설정 화면에서 실패 규칙을 고를 수 있다 — 같은 미션 한 번 더(기본) / 다른 미션으로 한 번 더 / 별 없이 다음 차례
- [x] **CFG-02**: 강사는 설정 화면에서 기본 라운드 수를 정할 수 있다
- [x] **CFG-03**: 강사는 설정 화면에서 출발 칸 보너스 별을 끔 / +1(기본) / +2 중에서 정할 수 있다
- [x] **CFG-04**: 강사는 설정 화면에서 보드 크기를 16 / 20(기본) / 24칸 중에서 정할 수 있다

### 시작 화면 (SETUP)

- [x] **SETUP-07**: 사용자는 각 플레이어/팀에 동물 캐릭터를 골라 배정할 수 있다 (v1의 남/여 캐릭터 선택을 대체)
- [x] **SETUP-08**: 사용자는 이번 게임의 라운드 수를 고를 수 있고(설정의 기본 라운드 수가 초깃값), 참가자 수 × 라운드 수로 계산한 예상 소요 시간이 표시된다
- [x] **SETUP-09**: 보드에 놓일 난이도의 미션이 하나도 없으면 게임 시작 전에 안내한다 (v1 MISSION-07 확장)

### 순환판 (BOARD)

- [x] **BOARD-01**: 출발 칸·퀘스트 칸·이벤트 칸으로 된 사각 순환판이 3D로 표시되고, 세로 폰 화면에서도 판 전체가 한 화면에 들어온다
- [x] **BOARD-02**: 출발 칸이 랜드마크로 확연히 구분되고, 칸마다 진행 방향이 표시되며, 칸은 서로 간격을 두어 하나씩 셀 수 있다
- [ ] **BOARD-03**: 도착 전에 칸 종류를 구분할 수 있다 — 퀘스트 칸은 난이도 색과 받을 별 개수로, 이벤트 칸은 모양·아이콘으로 (글자 없이)
- [x] **BOARD-04**: 칸 배치(퀘스트 칸 난이도, 이벤트 칸의 이벤트)는 게임 시작 때 가중치에 따라 정해지고 게임 중에는 바뀌지 않는다
- [ ] **BOARD-05**: 한 칸에 말이 여러 개(최대 8개) 서 있어도 모든 말이 구분된다

### 턴 흐름 (TURN)

- [x] **TURN-01**: 현재 차례에서 주사위 버튼을 누르면 주사위(1~6) 연출 후 그 수만큼 말이 칸마다 이동하며, 출발 칸을 지나 순환판을 계속 돈다
- [x] **TURN-02**: 퀘스트 칸에 멈추면 그 칸 난이도의 미션이 한 장 뽑혀 이름·설명·받을 별 개수가 크게 표시된다
- [x] **TURN-03**: 강사가 성공/실패를 판정하고, 성공하면 난이도별로 별을 받는다 (쉬움 ⭐1 / 보통 ⭐2 / 어려움 ⭐3)
- [x] **TURN-04**: 실패하면 설정된 실패 규칙대로 진행되며(재도전은 1회까지), 어떤 경우에도 별은 줄지 않는다
- [x] **TURN-05**: 이벤트 칸에 멈추면 이벤트 효과(앞으로 N칸 / 뒤로 N칸 / 한 번 더)가 적용되고, 이벤트로 이동해 퀘스트 칸에 닿으면 그 퀘스트를 수행한다 (이벤트 연쇄 발동은 없음)
- [x] **TURN-06**: 출발 칸을 앞으로 지나가거나 출발 칸에 멈추면 설정된 보너스 별을 받는다 — 뒤로 지날 때는 받지 않고, 같은 바퀴에 두 번 받지 않는다
- [x] **TURN-07**: "한 번 더"는 같은 플레이어가 추가 턴을 하며, 라운드 수에는 세지 않고 연속 1회까지만 허용된다
- [x] **TURN-08**: 강사는 직전 성공/실패 판정을 되돌릴 수 있다

### 라운드 & 승리 (ROUND)

- [x] **ROUND-01**: 모든 플레이어/팀이 정규 턴을 한 번씩 마치면 1라운드이며, 팀전에서는 팀 단위로 턴을 세고 팀원이 돌아가며 수행한다
- [x] **ROUND-02**: 화면에 현재 라운드 / 전체 라운드가 표시되고, 마지막 라운드가 시작되면 "마지막 라운드!" 알림이 나온다
- [x] **ROUND-03**: 정한 라운드가 모두 끝나면 게임이 종료되고 별이 가장 많은 플레이어/팀이 승리하며, 동점이면 공동 우승이다
- [x] **ROUND-04**: 강사는 언제든 확인을 거쳐 "지금 끝내기"로 게임을 끝내고 시상식으로 갈 수 있다

### 화면 정보 (HUD)

- [ ] **HUD-01**: 별 점수판에 모든 플레이어/팀의 별 개수가 별 순으로 정렬되어 표시되고(동점은 같은 등수), 보드의 말과 같은 캐릭터 아이콘으로 대응된다
- [x] **HUD-02**: 지금 차례(팀전이면 팀 이름과 지금 뛸 팀원 이름)와 다음 차례가 표시된다
- [x] **HUD-03**: 주사위·이동·연출이 진행되는 동안 진행 버튼이 숨겨지고, 연출이 끝나야 다음 단계로 넘어간다
- [ ] **HUD-04**: 버튼은 크고 단순하며 글자를 최소화해 아동이 쉽게 조작할 수 있다

### 캐릭터 (CHAR)

- [ ] **CHAR-01**: 말은 코드로 만든 귀여운 치비 동물 캐릭터이며 여러 종(6~8종)이 있다 (외부 3D 모델 파일 없음)
- [ ] **CHAR-02**: 캐릭터는 상황에 따라 표정이 바뀐다 — 기본 / 두근 / 기쁨(^^ 눈) / 아쉬움 / 놀람 / 우승
- [ ] **CHAR-03**: 캐릭터는 대기, 칸 이동 점프, 성공 점프·회전, 실패 아쉬움, 우승 환호 동작을 한다

### 성공 연출 (FX)

- [ ] **FX-01**: 퀘스트에 성공하면 성공 애니메이션이 나온다 — 캐릭터 점프·회전·팔 들기, 컨페티, 별 버스트, 바닥 충격파 링
- [ ] **FX-02**: 큰 별이 캐릭터 위에서 점수판으로 날아가 점수가 오르고 "퀘스트 성공! ⭐+N" 배너가 표시된다
- [ ] **FX-03**: 성공 판정부터 다음 진행이 가능해질 때까지 2.5초 이내이며, 화면을 탭하면 연출을 건너뛸 수 있다 (별은 그대로 지급)
- [ ] **FX-04**: 난이도가 높을수록 성공 연출이 더 커진다 (예: ⭐3은 화면 흔들림 추가)
- [ ] **FX-05**: 실패하면 1초 이내로 짧고 다정한 반응이 나온다 (빨간 X·버저음 없음)
- [ ] **FX-06**: 출발 보너스와 이벤트 발동도 짧은 연출로 알려 준다

### 시상식 (END)

- [ ] **END-01**: 게임이 끝나면 시상대에 우승자(공동 우승 포함)가 서고 모든 플레이어/팀의 별 개수가 표시되며, 꼴찌는 강조하지 않는다
- [ ] **END-02**: 시상식에서 승패와 별개인 칭찬 배지(예: 도전왕, 끈기왕, 여행왕)를 준다
- [ ] **END-03**: 사용자는 시상식에서 "다시 하기" 또는 "처음으로"를 고를 수 있다

### 사운드 (AUDIO)

- [ ] **AUDIO-01**: 주사위·이동·퀘스트 성공·별 획득·시상식에 효과음이 나온다 (CC0 소리만 사용)
- [ ] **AUDIO-02**: 사용자는 효과음을 켜고 끌 수 있다

### 안정성 (STAB)

- [ ] **STAB-01**: 새로고침 없이 여러 판(5판)을 연속으로 해도 느려지거나 멈추지 않는다
- [x] **STAB-02**: 다른 앱에 다녀와 3D 화면이 꺼지면 "화면 다시 그리기"로 진행 상황을 그대로 유지한 채 복구할 수 있다
- [ ] **STAB-03**: iPhone·iPad Safari와 노트북 Chrome에서 원활하게 동작한다 (실기기로 확인)
- [ ] **STAB-04**: 인터넷 연결이 없어도 모든 글자와 화면이 정상 표시된다 (외부 CDN 요청 없음)

## Out of Scope

| Feature | Reason |
|---------|--------|
| 온라인 멀티플레이어 / 여러 기기 실시간 동기화 | 강사 기기 1대 로컬 운영으로 충분, 서버 복잡도·비용 과다 |
| 계정 / 로그인 / 인증 | 단일 기기 현장 운영이라 불필요 |
| 줄넘기 성공 자동 판정(센서/영상 인식) | 강사 수동 판정으로 대체 |
| 실제 브랜드 / 저작권 캐릭터 / 상표 사용 | 오리지널 디자인만 사용 |
| 결제 / 수익화 | 강습 도구, 수익 모델 없음 |
| 물리 엔진 기반 주사위/캐릭터 | 턴제 보드게임에 과함 — 트윈 애니메이션으로 대체 |
| 게임 전체 시간 제한 타이머 | v2.0 결정: 라운드 수로만 종료. 타이머는 턴 중간 종료·불공정을 만든다 (v1 타이머 제거) |
| 강사 설정을 백업 파일(JSON)에 포함 | v2.0 결정: 설정은 기기에만 저장. 저장 형식을 올리지 않아 기존 데이터·백업 파일 호환을 지킨다 |
| 돈·땅 구매·통행료 | 아동 수업에 불필요한 복잡도, 보상은 별 하나 |
| 별 잃기·별 뺏기·탈락 | 실제 운동으로 번 별을 빼앗으면 노력이 무의미해짐 |
| 외부 3D 캐릭터 모델(.glb) | 표정 변화 불가 — 코드 생성 캐릭터로 결정 (2026-10-22 비교 데모) |
| 3D 공간 안의 한글 텍스트 | 폰트를 CDN에서 받아 오프라인 교실에서 깨짐 — 글자는 모두 화면(DOM)에 |
| 주사위 2개·더블 | 덧셈 부담, 라운드 공정성 훼손 |
| 칸 하나하나 편집하는 보드 에디터 | 효과 대비 비용 큼 — 가중치·프리셋으로 충분 |
