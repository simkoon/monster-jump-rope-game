# 파워점핑 — 신나는 줄넘기 미션

## What This Is

줄넘기 강습용 3D 웹 보드게임이다. 아이들이 카드로 뽑은 줄넘기 미션(기술)을 실제로 수행해 성공하면 주사위를 굴려 보드 위를 전진하고, 결승점에 먼저 도착한 플레이어·팀이 승리한다. 강사가 미션과 이벤트 칸을 직접 추가·수정·삭제할 수 있어 수업 커리큘럼에 맞게 자유롭게 커스터마이징할 수 있다. 대상은 줄넘기 수업을 듣는 아동이며, 운영은 강사가 기기 1대로 진행한다.

## Core Value

카드로 뽑은 줄넘기 미션을 실제로 성공 → 주사위 → 전진 → 먼저 도착하면 승리, 이 핵심 게임 루프가 아이들에게 신나고 매끄럽게 돌아가는 것. 그리고 강사가 미션을 자유롭게 관리(추가/수정/삭제)할 수 있는 것.

### Active

- [ ] 미션 수행 판정: 뽑힌 줄넘기 미션을 실제로 수행 → "성공/실패" 버튼으로 강사가 수동 판정
- [ ] 성공 시 주사위 등장 → 굴려서 나온 수만큼 보드에서 전진

### Out of Scope

- 온라인 멀티플레이어 / 여러 기기 실시간 동기화 — 강사 기기 1대 로컬 운영으로 충분, 클라우드 서버는 복잡도·비용 과다
- 계정/로그인/유저 인증 시스템 — 수업 현장 단일 기기 운영이라 불필요
- 실제 브랜드·저작권 캐릭터·상표 사용 — 오리지널 디자인만 사용
- 줄넘기 성공 자동 판정(센서/영상 인식) — 강사가 눈으로 보고 수동 판정하는 방식으로 대체 (v1 범위 밖)
- 결제/수익화 기능 — 강습 도구, 수익 모델 없음

## Context

- **사용자**: 줄넘기 강사(운영자)와 아동 수강생(플레이어). 요청자는 실제 줄넘기 강사.
- **운영 환경**: 수업 현장에서 강사 기기 1대(노트북/태블릿)로 화면을 띄워 진행. 아이들이 화면 앞에서 미션을 수행.
- **핵심 상호작용**: 게임 진행 판정(성공/실패)은 강사가 수동으로 내림. 게임은 카드→미션→주사위→이동→이벤트의 보드게임 루프.
- **커스터마이징 중심**: 강사마다 수업 커리큘럼이 달라 미션·이벤트를 자유롭게 편집하는 것이 필수. 편집한 내용은 저장·백업·공유(파일)될 수 있어야 함.
- **3D 요구**: 사용자가 명시적으로 3D 게임을 원함. 웹 브라우저에서 설치 없이 실행되도록 함.

## Constraints

- **Tech stack**: 웹 브라우저 + Three.js(WebGL) 3D 렌더링 — 사용자가 3D + 브라우저 실행을 원함, 설치 불필요
- **Platform**: 최신 브라우저(Chrome 등) 지원 — 강사 기기 1대 운영
- **Data**: 서버 없이 localStorage + 파일(JSON) 내보내기/가져오기 — 단일 기기 로컬 운영, 백업·공유 필요
- **Audience**: 아동 대상 — UI는 크고 단순하게, 색상은 밝고 경쾌하게(닌텐도풍), 텍스트 최소화
- **IP**: 실제 브랜드/상표/저작권 자산 미사용 — 오리지널 아트·로고만
