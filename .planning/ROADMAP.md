# Roadmap: 파워점핑 — 신나는 줄넘기 미션

## Milestones

- ✅ **v1.0 파워점핑 기본 게임** — Phases 1–4.1 (13 plans, 2026-07-25 ~ 2026-08-05 완료). 아카이브: [`.planning/milestones/v1.0-ROADMAP.md`](milestones/v1.0-ROADMAP.md)
- 🚧 **v2.0 3D 블루마블 재구축** — Phases 5–8 (진행 중)

## Overview

v2.0은 v1의 "카드 → 판정 → 주사위 → 결승 레이스" 게임을 블루마블식 "주사위 → 이동 → 도착 칸 퀘스트 → 판정 → 별" 순환판 게임으로 바꾸고, 2D 화면을 다시 3D(R3F)로 만든다. 순서는 v1에서 효과를 본 원칙을 그대로 따른다: **규칙과 데이터를 먼저 헤드리스로 고정하고, 그 위에 3D를 얹는다.** Phase 5는 강사가 만든 미션·이벤트를 하나도 잃지 않는 저장 계층, 강사 설정, 새 규칙 엔진을 만들어 임시 DOM 화면으로 게임 한 판을 끝까지 플레이할 수 있게 한다. 복구 비용이 가장 큰 위험(저장 데이터 손실)과 테스트로 싸게 막을 수 있는 위험(순환 이동 계산 오류)을 가장 먼저 처리하는 단계다. Phase 6은 3D 사각 순환판·주사위·카메라·연출 디렉터와 DOM 화면 정보(점수판·차례·라운드)를 세워 임시 화면을 교체한다(말은 아직 임시 말). Phase 7은 그 위에 코드로 만든 치비 동물 캐릭터와 표정·동작을 얹는다. Phase 8은 이번 마일스톤의 대표 경험인 퀘스트 성공 연출과 시상식, 효과음, 연속 플레이·실기기 안정성으로 마무리한다. 미션·이벤트 편집기와 개인전/팀전 설정은 v1에서 검증된 그대로 재사용한다.

**더 깊은 확인이 필요한 단계:** Phase 6(iOS Safari 3D 화면 꺼짐 복구, 세로 화면 카메라 맞춤 — 실기기 스파이크), Phase 7(코드로 만든 캐릭터의 귀여움 — 디자인 스파이크, 8인 드로우콜 실측), Phase 8(3D 캐릭터 위치 → DOM 점수판 별 비행 좌표 정합).

## Phase Details

### Phase 5: 새 규칙 엔진 & 강사 설정

**Goal**: 3D 없이(임시 DOM 화면) 강사가 설정을 고르고, 순환판 새 규칙(주사위 → 이동 → 도착 칸 퀘스트 → 판정 → 별, 정한 라운드가 끝나면 별 최다 승리)으로 게임 한 판을 처음부터 끝까지 플레이할 수 있다. 이 과정에서 v1에서 만든 미션·이벤트와 예전 백업 파일은 하나도 잃지 않는다.
**Depends on**: Phase 4.1 (v1.0 완료 — 편집기·저장·헤드리스 엔진·엔진-스토어 브리지를 이어받음)
**Requirements**: DATA-05, DATA-06, DATA-07, CFG-01, CFG-02, CFG-03, CFG-04, SETUP-07, SETUP-08, SETUP-09, BOARD-04, TURN-01, TURN-02, TURN-03, TURN-04, TURN-05, TURN-06, TURN-07, TURN-08, ROUND-01, ROUND-03, ROUND-04
**Success Criteria** (what must be TRUE):

  1. 미션·이벤트를 만들어 둔 v1 기기를 v2로 업데이트해도 미션·이벤트가 하나도 사라지지 않고, 예전에 내보낸 v1 백업 파일(JSON)도 그대로 가져와진다
  2. 강사가 설정 화면에서 실패 규칙(같은 미션 한 번 더 / 다른 미션으로 한 번 더 / 별 없이 다음 차례), 기본 라운드 수, 출발 보너스 별(끔 / +1 / +2), 보드 크기(16 / 20 / 24칸)를 고르면 새로고침 후에도 유지되고, 내보낸 백업 파일에는 설정이 들어가지 않는다
  3. 시작 화면에서 플레이어/팀마다 동물 캐릭터를 골라 배정하고 라운드 수를 정하면 예상 소요 시간이 표시되며, 보드에 놓일 난이도의 미션이 하나도 없으면 시작 전에 안내받는다
  4. 주사위를 누르면 1~6이 나오고 말이 그만큼 순환판을 돌아(출발 칸을 지나 계속) 칸에 멈춘다. 퀘스트 칸이면 그 칸 난이도의 미션이 뽑혀 이름·설명·받을 별 개수가 크게 보이고, 강사가 성공으로 판정하면 별(쉬움 ⭐1 / 보통 ⭐2 / 어려움 ⭐3)을 받는다. 실패하면 설정된 실패 규칙대로 진행되고(재도전 1회까지) 별은 절대 줄지 않으며, 강사는 직전 판정을 되돌릴 수 있다. 게임 시작 때 정해진 칸 배치는 게임 내내 바뀌지 않는다
  5. 이벤트 칸(앞으로 N칸 / 뒤로 N칸 / 한 번 더)과 출발 칸 보너스가 규칙대로 적용된다 — 이벤트로 퀘스트 칸에 닿으면 그 퀘스트를 수행하고, 뒤로 지날 때·같은 바퀴 두 번째는 보너스가 없으며, "한 번 더"는 라운드에 세지 않고 연속 1회까지다. 모든 플레이어/팀이 정규 턴을 한 번씩 마치면 1라운드가 지나고(팀전은 팀원이 돌아가며 수행), 정한 라운드가 끝나거나 강사가 확인을 거쳐 "지금 끝내기"를 누르면 별이 가장 많은 플레이어/팀이 우승(동점은 공동 우승)으로 표시된다

### Phase 6: 3D 순환판 & 게임 화면

**Goal**: 임시 화면이 3D 사각 순환판 게임 화면으로 바뀐다. 세로 폰 화면에서도 판 전체가 보이고, 처음 보는 아이도 3초 안에 출발 칸·진행 방향·칸 종류·별 1등·지금 차례를 읽을 수 있으며, 주사위·이동 연출이 끝나야 다음 단계로 넘어간다. 한글 글자는 모두 3D 밖 DOM 화면에 둔다. 말은 아직 임시 말이며 Phase 7에서 치비 캐릭터로 바뀐다.
**Depends on**: Phase 5
**Requirements**: BOARD-01, BOARD-02, BOARD-03, HUD-01, HUD-02, HUD-03, HUD-04, ROUND-02, STAB-02, STAB-04
**Success Criteria** (what must be TRUE):

  1. 게임을 시작하면 출발·퀘스트·이벤트 칸으로 된 3D 사각 순환판이 세로 폰 화면에서도 한 화면에 다 들어오고, 출발 칸은 랜드마크로 확연히 구분되며, 칸마다 진행 방향이 보이고 칸 사이 간격 덕분에 하나씩 셀 수 있다
  2. 아이가 말이 도착하기 전에 글자 없이 칸 종류를 구분할 수 있다 — 퀘스트 칸은 난이도 색과 받을 별 개수로, 이벤트 칸은 모양·아이콘으로
  3. 아이가 글자가 거의 없는 큰 주사위 버튼을 누르면 3D 주사위가 굴러 수가 나오고 말이 칸마다 한 칸씩 이동하며, 그동안 진행 버튼은 숨겨졌다가 연출이 끝나야 다시 나타난다
  4. 화면에 별 순으로 정렬된 점수판(동점은 같은 등수, 보드의 말과 같은 색·아이콘으로 대응), 지금 차례와 다음 차례(팀전은 팀 이름과 지금 뛸 팀원 이름), 현재 라운드 / 전체 라운드가 표시되고, 마지막 라운드가 시작되면 "마지막 라운드!" 알림이 나온다
  5. 다른 앱에 다녀와 3D 화면이 꺼져도 "화면 다시 그리기"를 누르면 별·위치·차례가 그대로 유지된 채 복구되고, 인터넷 연결이 없어도 모든 글자와 화면이 정상 표시된다

### Phase 7: 치비 동물 캐릭터 & 표정

### Phase 8: 퀘스트 성공 연출 & 시상식 & 마감

**Goal**: 퀘스트 성공이 이번 마일스톤의 대표 경험이 된다. 성공하면 2.5초 안에 끝나는 신나는 성공 애니메이션과 함께 큰 별이 점수판으로 날아가고, 게임이 끝나면 시상식에서 모두가 칭찬받는다. 효과음이 함께 나오며, iPhone·iPad·노트북에서 여러 판을 연속으로 해도 매끄럽게 돌아간다.
**Depends on**: Phase 7 (성공 연출이 캐릭터의 점프·회전·표정을 사용. 컨페티·별 비행 등 일부는 Phase 6 이후 임시 말로 병행 개발 가능)
**Requirements**: FX-01, FX-02, FX-03, FX-04, FX-05, FX-06, END-01, END-02, END-03, AUDIO-01, AUDIO-02, STAB-01, STAB-03
**Success Criteria** (what must be TRUE):

  1. 퀘스트에 성공하면 캐릭터가 점프·회전·팔 들기를 하고 컨페티·별 버스트·바닥 충격파 링이 터진 뒤, 큰 별이 캐릭터 위에서 점수판으로 날아가 점수가 오르고 "퀘스트 성공! ⭐+N" 배너가 뜬다. 난이도가 높을수록 연출이 더 커진다(⭐3은 화면 흔들림 추가)
  2. 성공 판정부터 다음 진행이 가능해질 때까지 2.5초를 넘지 않고, 화면을 탭해 연출을 건너뛰어도 별은 그대로 지급된다. 실패하면 1초 이내의 짧고 다정한 반응만 나오며(빨간 X·버저음 없음), 출발 보너스와 이벤트 발동도 짧은 연출로 알려 준다
  3. 게임이 끝나면 시상대에 우승자(공동 우승 포함)가 서고 모든 플레이어/팀의 별 개수와 승패와 상관없는 칭찬 배지(도전왕·끈기왕·여행왕 등)가 표시되며, 꼴찌는 강조되지 않고, "다시 하기" 또는 "처음으로"를 고를 수 있다
  4. 주사위·이동·퀘스트 성공·별 획득·시상식에 CC0 효과음이 나오고, 사용자가 효과음을 켜고 끌 수 있다
  5. 새로고침 없이 5판을 연속으로 해도 느려지거나 멈추지 않으며, iPhone·iPad Safari와 노트북 Chrome 실기기에서 원활하게 동작함이 확인된다
