## Spacing Scale

v1 base-4 스케일을 그대로 상속한다(CSS 변수 `--xs/--sm/--md/--base/--lg/--xl/--2xl/--3xl` 폴백 표기 관례 유지).

| Token | Value | Usage (Phase 5) |
|-------|-------|-----------------|
| xs | 4px | 이모지-글자 간격, 칸 타일 안쪽 여백, 점수판 행 내부 간격 |
| sm | 8px | 동물 버튼 격자 간격, 칸 줄 타일 간격, 스텝퍼 버튼 간격, 세그먼트 간격 |
| md | 12px | 설정 그룹 안 라벨→컨트롤→힌트 간격, 참가자 카드 내부 간격 |
| base | 16px | 시작 화면 필드 간 간격, 플레이 화면 섹션 간 간격, 설정 그룹 카드 패딩 |
| lg | 20px | 편집기 패널 패딩(상속), 플레이 화면 좌우 거터 |
| xl | 24px | 설정 그룹 사이 간격, 시작 화면 카드 패딩(상속), 큰 버튼 사이 간격 |
| 2xl | 32px | 퀘스트 카드 패딩(상속) |
| 3xl | 48px | 결과 화면 세로 패딩(상속) |
| 4xl | 64px | 편집기 페이지 하단 여백(상속) |

**터치 타깃 토큰 (상속, Phase 3):** `--tap: 72px`(주요 게임 버튼), `--tap-sm: 56px`(보조 컨트롤·동물 버튼·스텝퍼·칸 타일), `--hud-h: 88px`(상단 차례 바).

**Phase 5에서 새로 정하는 크기 (모두 4의 배수):**

| 요소 | 값 | 근거 |
|------|----|------|
| 설정 탭 스텝퍼 −/+ 버튼 | 48×48px | 편집기 화면용(강사 손가락, ≥44px). 게임 토큰 `--tap-sm`을 편집기에 섞지 않음 |
| 동물 버튼 | `--tap-sm` 정사각(56px, 폰 46px) | 아동이 직접 누름 |
| 선택된 동물 아바타 원 | 56px(`--tap-sm`) | 참가자 카드 머리 |
| 칸 타일 | 최소 너비 56px, 최소 높이 64px | 칸 종류 글리프 + 말 이모지 두 줄 |
| 임시 플레이 화면 최대 너비 | 720px, 가운데 정렬 | 태블릿 가로에서도 한 열로 읽힘 |

**Exceptions:** (1) 상속된 반지름(`--radius 22px`, `--radius-sm 16px`, 카드 18px, 알약 999px)은 간격이 아니라 반지름이라 예외. (2) `game.css`의 폰(≤560px) 축소값(`--tap 58px`, `--tap-sm 46px`, `--hud-h 60px`)과 `.app--playing` iPhone 블록의 비-4 값은 Phase 4.1에서 이미 승인된 **기존 예외**로 그대로 둔다. **Phase 5가 새로 쓰는 CSS 규칙은 위 표의 값만 사용**하고 새 비-4 값을 추가하지 않는다. 2D 보드용 `.board-2d`·`.board-*`·`.game-clock`·`.game-positions` 규칙은 삭제 대상(RESEARCH D-28 표)이다.

## Typography

화면별로 **크기 4개 이하** 원칙을 지킨다. 두 스케일은 한 화면에 섞지 않는다(v1 규칙 상속). 설정 탭 = 편집기 스케일, 시작·플레이·결과 = 게임 스케일. 예외 하나: 게임 화면 위에 뜨는 `ConfirmDialog`는 v1부터 편집기 모달 스타일을 쓰는 기존 컴포넌트라 그대로 둔다.

**굵기 — Phase 5 새 UI는 정확히 2개:** `800`(Extrabold: 기본 글자, 라벨, 힌트, 보조 버튼, 이름) / `900`(Black: 제목, 주요 버튼, 숫자 강조 — 별 개수·라운드·예상 분·주사위 눈). v1의 `500`("(선택)" 전용)은 이번 단계 새 화면에서 쓰지 않는다.

### S1 설정 탭 — 편집기 스케일 (상속 22/18/15/12 중 3개 사용)

| Role | Size | Weight | Line Height | 적용 |
|------|------|--------|-------------|------|
| Heading | 18px | 900 | 1.2 | 탭 제목 "⚙️ 게임 설정", 스텝퍼 숫자 |
| Body | 15px | 800 (선택된 세그먼트·스텝퍼 단위는 800, 탭 라벨 상속) | 1.5 | 세그먼트 버튼 글자(기존 `.seg button`은 14px → 설정 탭에서도 기존 컴포넌트 그대로 사용, 새 규칙 추가 안 함), 진행 중 게임 안내 배너, 스텝퍼 단위 "라운드" |
| Caption | 12px | 800 | 1.4 | 설정 항목 라벨(`.field > label` 패턴, `--ink-soft`), 힌트(`.hint`), 하단 저장 안내 |

> 기존 `.seg button { font-size:14px }`는 v1 편집기에서 승인·운영 중인 값이다. Phase 5는 그 컴포넌트를 **수정 없이 재사용**하므로 새 크기를 도입하지 않는다.

### S2~S4 게임 화면 — 게임 스케일 (상속 40/26/20/15, 폰 ≤560px에서는 30/22/17/14로 자동 축소)

| Role | Size | Weight | Line Height | 적용 |
|------|------|--------|-------------|------|
| Display | 40px | 900 | 1.1 | 시작 화면 선택된 동물 아바타 이모지, 차례 이름("곰돌이 차례"), 주사위 눈 "🎲 4", 결과 제목 "게임 끝!", 우승자 줄 |
| Heading | 26px | 900 | 1.2 | 퀘스트 미션 이름, 받을 별 줄 "⭐⭐", 판정 결과 줄, 결과 이유 문구, 동물 버튼 이모지, 스텝퍼 −/+ 기호 |
| Body | 20px | 900 (주요 버튼) / 800 (그 외) | 1.35 | 모든 버튼 글자, 이름 입력, 미션 설명, 점수판 이름·별 수, 예상 시간 "⏱️ 약 8분", 이동 줄·이벤트 줄, 라운드 숫자, 결과 순위 줄 |
| Caption | 15px | 800 | 1.4 | 필드 라벨, 난이도 배지, 칸 타일 글자("⭐2", "➡️3")·타일 안 말 이모지, 라운드 라벨, 예상 시간 기준 문구, 규칙 요약, 누락 안내, "재도전" 배지 |

**숫자:** 별 개수·라운드·예상 분·주사위 눈·순위는 `font-variant-numeric: tabular-nums`.
**글자 최소화:** 버튼은 이모지+동사 한 덩어리. 문장은 안내·힌트에만.

2. **지금 차례 강조**: 차례 알약 테두리(기존 `.game-turn-pill`), 점수판의 지금 차례 행 테두리 3px, 칸 줄에서 지금 차례 말이 있는 칸의 바깥 링 3px

4. 포커스 링 `outline: 3px solid var(--sky)` (전 화면)

## Screen Contracts

### S1 — 편집기 ⚙️ 설정 탭 (D-23, CFG-01~04, DATA-07)

**진입:** 편집기 탭 줄 `🎴 미션 [n]` · `🎲 이벤트 [n]` · **`⚙️ 설정`**(개수 알약 없음). `TabKey`에 `'settings'` 추가, 패널 `.panel--editor-shell` 안에 렌더. 헤더의 내보내기/가져오기는 그대로 보인다(설정은 거기 들어가지 않음).

**초점(focal point):** 맨 위 "미션에 실패하면" 세그먼트 — 수업 운영에 가장 큰 영향을 주는 설정이므로 첫 항목.

**레이아웃 (위→아래, 한 열, 최대 너비는 패널 상속):**
1. 제목 `⚙️ 게임 설정` (Heading 18/900) + 부제 한 줄(Caption 12/800 `--ink-soft`)
2. (조건부) 진행 중 게임 안내 배너 — `useGameStore.game !== null`일 때만. 바탕 `--panel-2`, 테두리 `--line` 2px, 반지름 `--radius-sm`, 패딩 12px 16px, Body 15/800.
3. 설정 그룹 4개 — 각 그룹은 `.field` 패턴: 라벨(Caption) → 컨트롤 → 힌트(`.hint`, Caption `--ink-soft`). 그룹 사이 24px.
   - **미션에 실패하면** — `SegmentedControl<FailRule>` 3택(`plain` sky 선택). 힌트는 **현재 선택값에 따라 바뀐다**(아래 문구 표). 폭 ≤560px에서는 세 버튼이 세로로 쌓인다(`.settings-failrule .seg { flex-direction: column }` — 새 규칙, 기존 `.seg`는 무수정).

## Interaction & Accessibility

- **애니메이션 없음(S3/S4):** 상태 전이는 즉시 다시 그리기. 버튼 누름 피드백(기존 `translateY`)만 유지. `prefers-reduced-motion` 전역 규칙 유지.
- **연타 안전:** 단계에 맞는 버튼만 렌더(표 참조) + 엔진 전이 첫 줄 phase 가드(RESEARCH Pitfall 5).
- **포커스:** 모든 버튼·세그먼트·동물 버튼에 `:focus-visible` 3px `--sky` 링. 단계가 바뀌면 새 주요 버튼으로 포커스를 옮기지 않는다(태블릿 터치 우선, 스크린리더는 `aria-live`로 안내).
- **live 영역:** 차례 알약, 판정 결과 줄, 예상 시간, 스텝퍼 숫자 = `aria-live="polite"`. 토스트는 기존 role=status.
- **색 독립:** 칸·배지·버튼·결과 줄 모두 이모지 또는 글자를 함께 쓴다(난이도 = 색 + ⭐수, 이벤트 = 점선 grape + ➡️/⬅️/🔁).
- **터치 타깃:** 게임 화면 ≥ `--tap-sm`(폰 46px — Phase 4.1 기존 예외), 편집기 설정 탭 ≥ 44px(스텝퍼 48px, 세그먼트 기존 높이 상속).
- **반응형:** 기준점 하나 — `max-width: 560px`(기존). 폰에서 동물 격자 4열, 실패 규칙 세그먼트 세로 쌓기, 주요 버튼 전체 폭.
- **입력 보안:** 참가자 이름·미션·이벤트 이름은 JSX 텍스트로만 렌더(`dangerouslySetInnerHTML` 금지 — v1 XSS 테스트 유지).
