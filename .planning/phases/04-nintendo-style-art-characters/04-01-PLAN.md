# 04-01 PLAN — Visual system + original "파워점핑" logo

## Goal
Start Phase 4 with a narrow, presentation-only slice: add a polished candy/playful visual system and an original `파워점핑` logo component, then apply it across the setup, play, result, and editor shells without touching the engine or store.

## Scope
- Add a reusable React text/logo component for the original `파워점핑` wordmark.
- Use CSS-only lettering treatment: rounded heavy text, white outline, candy gradient fill, toy-like shadow, and a rope motif.
- Extend existing Phase 1/3 colors (`--sky`, `--sun`, `--coral`, `--pink`, `--grass`, `--grape`) with only a small set of Phase 4 support tokens.
- Apply the treatment to:
  - Setup shell: replace the placeholder text logo.
  - Play shell: polish the stage, top HUD, buttons, mission/result panels, and rank strip.
  - Result shell: add the compact logo and candy result panel styling.
  - Editor shell: use the original logo in the header and add a Phase 4 app/panel/switch treatment.
- Keep Phase 3.1 board square numbers, direction arrows, finish landmark, token labels, dice icon, and highlight classes readable.

## Out Of Scope
- Situation-based pose/expression switching (`walk`, `cheer`, `hurt`) for Kenney characters. That is 04-02.
- New game rules, store state, engine behavior, or ANIM_DONE sequencing changes.
- Real brand references, copied franchise art, or trademarked assets.
- Browser deployment or committing.
