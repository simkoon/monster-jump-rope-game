## Scope rationale (14 files, kept as one plan on purpose)

RESEARCH Pitfall 2: turning ❌ into a 700 ms beat, stretching stars to 900 ms and adding the win beat breaks six existing test files at once (timeline, displayed, useDirector, stage, hud, App). `tsc -b` type-checks the tests and CI runs only the build, so the producer change and those test fixes must land in the same task — splitting them across plans would leave a red commit. To keep every task commit green the plan is cut at the only safe seam: Task 1 adds the beat TYPES, the timed-beat Banner and the win banner copy/CSS (nothing produces the new beats yet, so no existing test changes behavior); Task 2 switches the producer (buildTimeline + director + GameStage) and migrates every affected test in the same commit. 9 of the 14 files are tests; the production edits are small (one switch case, one branch, one handler, one CSS block).
