# Phase 3.1 Context — 2D 렌더링 전환 & CC0 에셋 파이프라인

## 전환 결정 (2026-07-26, 사용자)

렌더링을 3D(Three.js/R3F) → **2D(DOM + SVG + CSS)** 로 전환한다.

**이유:** 이 프로젝트에는 3D 캐릭터·표정 리깅을 조달할 수단이 없다. 반면 2D는 CC0
무료 에셋으로 즉시 조달 가능하며, 실제로 남/여 캐릭터 + 포즈 + 표정 파츠가 확보됨을
아래와 같이 검증했다.

**확정 사항:**

- 렌더링: DOM + SVG + CSS (신규 렌더링 의존성 없음)
- 기존 3D 코드: **완전 제거** (`src/game/scene/` 삭제, three/@react-three/* 4종 언인스톨)
- 에셋 조달: CC0 팩 다운로드 우선

## 사용자 디자인 피드백 (2026-07-26)

시안을 본 뒤 나온 지시. Phase 3.1 설계의 하드 제약으로 취급한다.

### 1. 칸 간격 — 타일이 너무 붙어 있다

> "칸수가 너무 붙어있고 조금씩 떨어져 있으면 좋겠어"

보드 칸 사이에 **시각적 간격(gap)** 을 둔다. 현재는 타일이 맞붙어 하나의 띠처럼
보인다. 칸이 개별 단위로 세어질 수 있어야 한다 — 아이가 "내가 몇 칸 갔는지" 눈으로
셀 수 있는 것이 이 게임의 핵심 피드백이기 때문이다.

- 2D 보드 레이아웃 모듈은 타일 크기와 **간격을 별도 파라미터**로 노출할 것
  (하드코딩된 인접 배치 금지)
- 간격은 이동 애니메이션 경로에도 반영된다 — 말이 칸에서 칸으로 "건너뛰는" 느낌이
  살아야 한다

### 2. 말(토큰) — 도형이 아니라 캐릭터여야 한다

> "움직여지는 말의 도형이 너무 일차원적인거같아 캐릭터가 있으면 좋겠어"

플레이어 말을 **기하학적 도형에서 캐릭터 스프라이트로 교체**한다.

- Kenney **Shape Characters** 팩은 이 지시에 위배되므로 **사용 금지** —
  원/사각형 몸통에 얼굴만 붙은 형태로, 사용자가 거부한 "도형" 그 자체다
- 대신 **Kenney Toon Characters** 의 `Male person` / `Female person` 사용 (아래)

### 3. 보드가 게임 상태를 전달하지 못한다 — **가장 중요한 지적**

> "움직여지는 칸들이 너무 붙어있고 어디로 움직여야하는지 명확하게 보이지않아서
> 마지막 도착지점이 어딘지도 몰라서 어느팀이앞서가는지 보이지도 않아서
> 스릴있어 보이지도않아"

이건 에셋·스타일 문제가 아니라 **정보 설계 실패**다. 보드를 다시 그리는 것만으로는
해결되지 않으며, Phase 3.1은 "3D→2D 포팅"이 아니라 **"보드가 게임 상태를 읽히게
만들기"** 로 범위를 넓혀야 한다.

분해하면 4개의 독립된 결함이다:

| # | 결함 | 필요한 것 |
|---|---|---|
| 3-1 | 진행 **방향**이 안 보인다 | 경로에 방향 표시(화살표/칸 번호), 시작→결승 순서가 한눈에 읽힐 것 |
| 3-2 | **결승점**이 어딘지 모른다 | 결승 칸을 명확한 랜드마크로 (깃발·아치·골 표식 + 다른 칸과 확연히 다른 크기·색) |
| 3-3 | **누가 앞서는지** 안 보인다 | 팀/플레이어 진행도 비교 UI (순위, 남은 칸 수, 진행 바) |
| 3-4 | **스릴**이 없다 | 접전·역전·결승 임박 순간을 시각적으로 강조 |

**설계 원칙:** 아이가 보드를 3초 보고 "① 어느 방향으로 가는지 ② 골이 어딘지
③ 내가 몇 등인지 ④ 얼마나 남았는지"에 답할 수 있어야 한다.

**주의 — 요구사항 공백:** 현재 REQUIREMENTS.md에는 "진행 상황·순위를 시각적으로
비교한다"에 해당하는 항목이 **없다**. LOOP-09는 승리 판정만 다룬다. 3-3/3-4는
기존 요구사항으로 커버되지 않는 신규 요구사항이므로, 계획 전에 REQUIREMENTS.md에
정식 추가해야 한다 (사용자 확인 필요).

**주의 — 기존 자산 재검토:** `moveHighlight.ts`(목적지 하이라이트)는 3-1의 부분
해법으로 이미 존재한다. 2D에서 폐기하지 말고 **확장**할 것.

### Toon Characters 상세 — 요구사항 직결

`Male person` / `Female person` 두 캐릭터가 동일 세트로 제공된다 (Robot/Zombie도
들어있으나 아동용이 아니므로 반입하지 않는다).

- 규격: **96 × 128 PNG** (HD 변형 및 Vector/SVG 동봉)
- 포즈: `idle`, `jump`, `walk0`~`walk7`(8프레임), `cheer0`/`cheer1`, `hurt`,
  `talk`, `think`, `rope`, 그 외 다수
- 표정 파츠(분리 PNG): `head`, `headFocus`, `headShock`
