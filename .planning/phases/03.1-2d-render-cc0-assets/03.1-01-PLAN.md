# 03.1-01 PLAN — 2D 렌더링 전환 & 진행 가독성 복구

## Goal
Phase 3의 Three.js/R3F 보드를 DOM+CSS 기반 2D 보드로 교체하고, 사용자가 지적한 핵심 문제(칸 구분, 진행 방향, 결승점, 순위/남은 거리, 캐릭터 말)를 해결한다.

## Scope
- Remove Three/R3F runtime and tests.
- Preserve existing engine/store/ANIM_DONE contracts.
- Convert board coordinate model to renderer-neutral 2D grid coordinates.
- Render a countable snake board with visible direction arrows and finish landmark.
- Replace geometric placeholder tokens with simple CC0 character sprites.
- Show rank and remaining-distance readout for LOOP-12.
- Keep move preview/highlight behavior in 2D.

## Acceptance Criteria
- `package.json` no longer depends on `three`, `@react-three/fiber`, `@react-three/drei`, `@react-three/test-renderer`, or `@types/three`.
- `src/game/scene/BoardScene.tsx` renders DOM-based 2D board without WebGL.
- Board shows separated tiles, square numbers, direction arrows, START/FINISH, and finish landmark.
- Player/team tokens are character sprites, not primitive 3D shapes.
- Position readout shows rank and remaining distance to finish.
- Card draw → success → dice → movement still advances game state.
- `npm run build` passes.
- `npm test` passes.
- Browser smoke confirms the 2D board appears and the bottom HUD does not occlude finish tile.
