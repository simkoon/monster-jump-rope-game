# 03.1-02 PLAN — Kenney CC0 에셋 반입 & 토큰 교체

## Goal
03.1-01에서 만든 임시 SVG 캐릭터 토큰을 실제 Kenney CC0 에셋으로 교체하고, 출처/라이선스를 프로젝트 안에서 추적한다.

## Scope
- Verify Kenney asset pages and zip download URLs.
- Download Toon Characters and optionally Board Game Icons.
- Import only the minimal selected files needed for v1 tokens/dice/readability.
- Keep assets under `public/assets/cc0/kenney/` with source/license notes.
- Update `BoardScene` sprite mapping from placeholder SVGs to Kenney files.
- Keep engine/store/ANIM_DONE unchanged.

## Acceptance Criteria
- `public/assets/cc0/kenney/` contains selected Kenney files plus license/source note.
- Board tokens render from Kenney character assets, not project placeholder SVGs.
- Placeholder SVGs are either removed or documented as no longer used.
- `npm run build` passes.
- `npm test` passes.
- Browser smoke confirms board starts and token images load without broken image errors.

## Verification
- `npm run build`
- `npm test`
- Browser smoke with console check for broken images.
