<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| imported file → app state | A user-selected `.json` file is fully untrusted: it may be malformed, oversized, wrong-version, or hostile |
| instructor text input → DOM render | Event names/labels are free text rendered back into the editor UI |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-05 | Tampering / DoS | lib/io.ts importContent | medium | mitigate | Validate-before-commit: JSON.parse in try/catch → `ContentSchema.safeParse` (with `version` as `z.literal(1)`, so future/foreign versions are cleanly rejected) → explicit ConfirmDialog → `store.replaceAll`. `replaceAll` is reachable ONLY from the validated+confirmed branch; any failure leaves existing data untouched (DATA-04). |
| T-01-06 | DoS (local) | lib/io.ts importContent | low | mitigate | Reject files larger than ~5MB before `readAsText` so a giant file cannot freeze the tab. |
| T-01-07 | Injection (XSS) | EventCard, EventModal | medium | mitigate | Render event name/label/effect text as JSX children (React auto-escapes); never inject imported or typed strings as raw HTML. |
</threat_model>
