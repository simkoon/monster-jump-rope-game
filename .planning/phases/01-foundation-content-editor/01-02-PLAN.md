## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-03 | Information Disclosure / Injection (XSS) | MissionCard, CategoryPicker, MissionModal | medium | mitigate | Render every user-supplied string (mission name/desc, category names) as JSX children so React auto-escapes it; never assemble card/label markup from raw HTML strings and never use raw-HTML injection for editor content. Covered by the positive escaping test (a markup-containing name renders as literal text). |
| T-01-04 | Tampering | MissionModal → store | medium | mitigate | The form commits to the store only through `zodResolver(MissionSchema)` on a valid submit; invalid input (empty name, out-of-enum difficulty) is blocked before any `addMission`/`updateMission`, keeping the store shape valid for Phase 2. |
</threat_model>
