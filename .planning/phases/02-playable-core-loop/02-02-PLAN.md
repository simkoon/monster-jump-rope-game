<objective>
Deliver the start/setup vertical slice on top of the pure engine: a throwaway plain-DOM setup screen where the teacher configures a game (mode, counts, names, characters, board preset, time limit) and presses 시작 to launch it, plus the thin zustand bridge that wires the harness to the engine transitions. After this plan a real user can configure and START a game; the empty-mission guard blocks a start with no missions.

Purpose: Make the engine reachable by a human (SETUP-01..06) and enforce MISSION-07 at the point of start. This UI is deliberately minimal and disposable — Phase 3 replaces it with the real child-friendly 3D UI (D-09). The engine-store bridge built here is the single seam between the durable engine and the throwaway UI.
Output: `src/harness/{useGameStore,SetupScreen,GameHarness}.tsx?` wired into `src/App.tsx`, with tests for the bridge and the empty-list guard.
</objective>
