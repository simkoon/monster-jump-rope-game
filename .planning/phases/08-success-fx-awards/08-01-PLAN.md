## Artifacts this phase produces

(This plan's share of the phase artifacts.)

**src/engine/state.ts** — new `export interface PlayerStats { attempts: number; successes: number; failures: number; retrySuccesses: number; hardSuccesses: number; luckyCount: number }`; new field `GameStateCore.stats: Readonly<Record<string, PlayerStats>>` (so `UndoSnapshot` carries it).

**src/engine/stats.ts** (new, pure) — `EMPTY_STATS` (frozen all-zero PlayerStats), `initStats(ids: readonly string[])`, `bumpStats(stats, pid, delta: Partial<PlayerStats>)` (returns a new record, adds the deltas), `isLuckyEvent(ev: Pick<Event, 'eff' | 'label'>, suppressed: boolean): boolean`.

**src/engine/game.ts** — `createGame` initializes `stats`; `judge` and `rollDice` return updated `stats` on every path.

**src/game/awards.ts** (new, pure) — `export type BadgeId = 'master' | 'persistent' | 'lucky' | 'traveler' | 'challenger' | 'cheer'`, `BADGE_PRIORITY: readonly BadgeId[]` (master, persistent, lucky, traveler, challenger, cheer), `MAX_SHOWN_BADGES = 2`, `awardBadges(stats, participants: readonly { id: string; travel: number }[]): Record<string, BadgeId[]>` (each list in priority order), `displayBadges(ids: readonly BadgeId[]): BadgeId[]`.

**Tests** — `src/engine/stats.test.ts`, `src/game/awards.test.ts` (new); `src/engine/game.test.ts`, `src/engine/fuzz.test.ts` (extended).
