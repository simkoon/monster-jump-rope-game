파워점핑 UAT 매뉴얼

기계로 확인할 수 있는 것은 모두 통과했습니다(테스트 1562개, 빌드 통과). 이 매뉴얼은 사람이 직접 보고 판단해야 하는 25가지를 순서대로 안내합니다. 각 항목에 확인 방법, 합격 기준, 헤드리스 Chrome으로 찍은 실제 화면을 붙였습니다. 결과 버튼을 누르면 이 기기 브라우저에 저장되고, 맨 아래 결과 복사로 한 번에 Claude에게 붙여 넣을 수 있습니다.

1. 게임 열기

노트북에서 dev 서버가 켜져 있어야 합니다.

http://localhost:5174/monster-jump-rope-game/

아이폰·아이패드(같은 Wi-Fi):

http://192.168.219.50:5174/monster-jump-rope-game/

서버가 꺼졌으면 프로젝트 폴더에서 npx vite --host --port 5174. IP는 바뀔 수 있으니 터미널의 Network 주소를 쓰세요.

2. 함께 쓰는 dev 화면

  • gallery.html 캐릭터 8종 × 표정 갤러리
  • soak.html?games=5 5판 자동 연속 플레이 + 수치 표 (&seed=7을 붙이면 같은 판 되풀이)
  • 노트북 Chrome 콘솔에서 window.__loseContext() 3D 화면 강제 끄기(11번)
