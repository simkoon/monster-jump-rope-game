# Phase 8 — UI Design Contract

> 퀘스트 성공 대형 연출(등급별), DOM 별 비행, 다정한 실패·보너스·이벤트 짧은 연출, 탭 건너뛰기, 시상식 화면(3D 시상대 + DOM 패널, DOM 대체 시상대), 칭찬 배지, 효과음과 🔊/🔇 토글의 화면·상호작용 계약이다. gsd-ui-researcher가 만들고 gsd-ui-checker가 검증한다.
> **자동 모드:** 사용자가 이번 단계의 디자인 결정을 모두 맡겼다("ㄱㄱ", Phase 7과 같은 방식). CONTEXT.md D-01~D-24는 잠긴 [auto] 결정이다. 그 밖에 직접 고른 값은 **[auto]**로 표시하고 한 줄 근거를 붙였다. 사람의 감각이나 실기기로만 확인할 수 있는 항목은 끝의 **UAT checks**에 모았다(중간 차단 체크포인트 없음). RESEARCH Open Questions 1~3은 §F3·§F7·§F5에서 확정했다.
> **이 계약은 Phase 6·7 UI-SPEC을 확장한다.** 여기에 적지 않은 토큰·타이포·간격·HUD(S1~S7)·캐릭터(C1~C8)는 앞 계약 그대로다. 앞 계약 문장을 바꾸는 곳은 §"Phase 6·7 계약 변경점"에 모두 모았다.
> **목표 느낌:** 성공은 "와!" 하고 터지고 2초 남짓 만에 깔끔하게 끝난다. 난이도가 높을수록 확실히 더 크다. 실패는 토닥이는 느낌이고, 시상식에서는 모두가 웃는다. 꼴찌는 눈에 띄지 않는다. 견본보다 확실히 더 귀엽게 만든다(사용자 기억).

## Typography

Phase 6 게임 스케일을 그대로 쓴다. 크기 4개(Display 40 / Heading 26 / Body 20 / Caption 15, 폰 ≤560px에서 30/22/17/14로 자동 축소), **굵기 2개: 800 / 900.** 새 크기·굵기는 없다. 등급별 "더 큰" 느낌은 글자 크기가 아니라 배너 폭·등장 튐(scale)·테두리로 낸다.

| Role | Size | Weight | Line Height | Phase 8 적용 |
|------|------|--------|-------------|--------------|
| Display | 40px | 900 | 1.1 | 성공 배너 큰 줄 `⭐+{n}`, 시상식 제목 `게임 끝!`, DOM 대체 시상대 우승자 이모지(≤4명) |
| Heading | 26px | 900 | 1.2 | 성공 배너 위 줄 `퀘스트 성공!`, soft 배너 한 줄, 시상식 우승 줄 `🏆 우승! …`, 🔊/🔇 이모지, DOM 대체 시상대 👑, 우승자 이모지(5~8명) |
| Body | 20px | 900(별 수 `⭐{n}`, `+{n}`, 버튼 글자) / 800(그 외) | 1.35 | 별 카드 이름(800)·별 수(900), `+{n}` 알약(900), 시상식 끝난 이유(800 `--ink-soft`), 시상식 버튼(900), 별 카드 아바타 이모지 |
| Caption | 15px | 800 | 1.4 | 배지 칩 `🏃 도전왕` 등 |

- 사용자 문자열(참가자·팀 이름)은 별 카드에서 한 줄 `text-overflow: ellipsis`. 우승 줄은 최대 2줄까지 쓰고 넘치면 말줄임(`line-clamp: 2`)한다. 전체 이름은 별 카드에 있다.
- 숫자(`⭐{n}`, `+{n}`)는 `font-variant-numeric: tabular-nums`.
- 설정 탭 새 그룹은 기존 편집기 스케일(`label`, `.hint` 12px)을 쓴다.

### F1 — 성공 연출 시간표 (`successPlan`, D-01~D-04, D-08)

**초점:** 0~0.7초는 **판정받은 캐릭터**(점프·회전·폭죽)가 첫 시선이고, 0.5초부터 **배너**, 0.6초부터는 **날아가는 큰 별**이 시선을 점수판으로 데려간다. 시선이 "캐릭터 → 별 → 내 점수 칸" 한 방향으로만 흐르게 한다.

비트 길이는 등급별 표 `STARS_MS = {1: 1600, 2: 1900, 3: 2200}`, reduced motion은 고정 1200ms다. 모든 시점은 순수 함수 `successPlan(stars, ms, reduced)` 하나가 정하고 Character·FxPools·CameraRig·Banner·StarFlight·useSfx가 같은 값을 읽는다(RESEARCH Pattern 2 비율: 배너 30%, 착지 35%, 비행 시작 40%, 도착 92%).

| 시점 | ⭐1 (1600) | ⭐2 (1900) | ⭐3 (2200) | reduced (1200) | 화면 |
|------|-----------|-----------|-----------|----------------|------|

| `bannerMs` | 480 | 570 | 660 | 0 | 성공 배너 등장(§F4) |
| `landMs` | 560 | 665 | 770 | — | 착지: 충격파 링 + 별 버스트 + 컨페티 방출, 성공 징글 시작. ⭐3은 카메라 흔들림 770→1090 |

### F2 — 3D 성공 효과 (lazy 3D 청크 `scene/FxPools.tsx`, D-06)

**원칙:** 풀 4개(컨페티·버스트·링·퍼프)를 첫 마운트 때 한 번만 만들고, 쉴 때는 `count = 0`이다. 성공마다 지오메트리·머티리얼을 만들지 않는다. `frustumCulled={false}`, instanceColor는 마운트 때 전부 미리 설정한다(첫 성공 끊김 방지, RESEARCH Pitfall 8). 비트가 끝나거나 바뀌면(건너뛰기 포함) 같은 프레임에 `count = 0`이다.

| 효과 | 모양 | 크기·움직임 | 수명 | 색 |
|------|------|-------------|------|-----|
| **컨페티** (CAP 160) | 얇은 직사각 종이 PlaneGeometry 0.07t × 0.12t, `DoubleSide` | 캐릭터 머리 높이에서 위쪽 원뿔로 발사: 위 속도 3.5~5.0 t/s, 옆 속도 1.0~2.2 t/s, 중력 −9 t/s², 조각마다 두 축으로 3~6 rad/s 팔랑 회전. 결정적 시드(비트 id) | ⭐1 900ms · ⭐2 1000ms · ⭐3 1150ms. 마지막 20%에 크기 1→0 | `FX_COLOR.confetti` / ⭐3 `confettiGold` |
| **별 버스트** (CAP 24) | 5각 별(Phase 6 칸 위 별 지오메트리 공유), 카메라를 향해 세움 | 착지 지점 높이 0.4t에서 화면 평면 방사형으로 균등 각도 + 작은 무작위(±8°), 속도 감속(easeOutCubic)으로 등급별 반경까지 | 500ms. 크기 0.6→1.0(0~30%) → 0(70~100%) | `FX_COLOR.burst` |

**카메라 흔들림(⭐3만, CameraRig 안):** `landMs`부터 **320ms**(≤ 350). 오프셋 x = A·e^(−t/0.1s)·sin(2π·18·t), y = 0.6·A·e^(−t/0.1s)·sin(2π·23·t + 1.3), **A = 0.06t**. 어느 화면에서도 화면 이동이 **6 css px를 넘지 않는다**(태블릿 가로 기준 약 5px, 폰 약 2~3px). 회전·줌은 흔들지 않는다. 끝나거나 비트가 바뀌면 정확히 fit 위치·lookAt으로 복원한다(RESEARCH Pitfall 7).

**드로우콜:** 평상시 ≤ 100(풀 4개 상시 마운트 포함 97), ⭐3 연출 중 보이는 메시 ≤ 104. 그림자·후처리 없음.

### F3 — DOM 별 비행 (`hud/StarFlight.tsx`, D-05)

**레이어:** `createPortal(…, document.body)`, 컨테이너 `position: fixed; inset: 0; pointer-events: none; z-index: 40`. HUD(차례 바·점수판·배너 z 3·소리 토글 z 4) 위, 모달(z 50)·토스트(z 80) 아래 **[auto]** — 연출 중 "지금 끝내기" 대화상자를 열면 대화상자가 별을 덮는 것이 맞다. `aria-hidden="true"`(장식. 같은 정보는 배너 `role="status"`와 점수판에 있다).

**별 모양(오리지널, 인라인 SVG `viewBox="0 0 64 64"`):** 둥근 꼭짓점 5각 별(`stroke-linejoin: round`), 채움 `--sun`, 선 3px `--sun-deep`. 왼쪽 위 흰 하이라이트 타원(α 0.6), **작은 잉크 눈 2개**(rx 3, ry 4.5, 간격 12) **[auto]** — "더 귀엽게"(사용자 기억)를 별에도 적용. 오른쪽 아래에 `+{n}` 알약(§Spacing, Body 900)을 붙이고 별과 같이 움직인다.

**좌표:** 시작 = 캐릭터 머리 위 앵커(`headAnchor` → `projectNdc` → `.stage-canvas` 사각형, 순수 계산), 끝 = `[data-pid="{pid}"] .sb-avatar`의 `getBoundingClientRect()` 중심. 둘 다 **비행 시작 순간에 한 번만** 잰다. 3D가 없거나(`!ready || failure`) 투영이 화면 밖·카메라 뒤면 **캔버스 셀 중앙**에서 출발한다.

**움직임:**

| 구간 | 길이 | 동작 |
|------|------|------|
| 등장 | `flyFromMs` + 160ms | 시작점에서 scale 0 → 1.2 → 1.0(easeOutBack), 회전 0 |
| 비행 | `flyFromMs + 160` → `flyToMs` (⭐1 672ms · ⭐2 828ms · ⭐3 984ms) | **위로 볼록한 포물선 호**: 바깥 요소가 x를 `ease-in-out`으로, 안쪽 요소가 y를 "먼저 위로, 그다음 끝점으로" 움직인다. 호의 꼭짓점은 두 끝점 중 높은 쪽보다 **max(64px, 세로 거리의 25%)** 위. 크기 1.0 → 0.5(도착하면 아바타 크기), 한 바퀴 회전(0 → 360°), 빛 유지 |
| 도착 | `flyToMs` + 80ms | 별 opacity 1→0. 같은 순간 그 칸 아바타에 **도착 반짝임**: 아바타 scale 1→1.25→1(240ms) + 해 빛 고리(§Color, 160ms), "딩" |
| 비트 끝 | `ms` | 숫자 증가 + 기존 `sb-body` pop. 점수판이 다시 정렬되어 칸이 옮겨져도 pop은 새 자리에서 일어난다(허용) |

- 구현은 CSS 변수(`--x0 --y0 --dx --dy --lift --fly-ms`) + keyframes다(jsdom에서 단언 가능, `Element.animate` 쓰지 않음). 변수에는 계산한 숫자만 넣는다(사용자 문자열 금지).
- 비트가 끝나거나 바뀌면 별 요소는 **즉시 제거**된다(`.fx-star` 0개, D-23).
- **reduced motion:** 비행·회전·크기 변화 없음. `flyToMs`(600ms)에 아바타 위(끝점)에 40px 별이 200ms 페이드인하고 비트 끝까지 머문 뒤 사라진다. 도착 반짝임 고리는 끄고, 숫자 증가는 그대로.

### F5 — 탭으로 건너뛰기 (`useSkipOnTap`, D-07)

| 항목 | 계약 |
|------|------|
| 대상 비트 | `stars`(성공), `win`(우승 배너), 시상식 등장 연출(지역 상태). `dice`·`hop`·`miss`·`startBonus`·`event`·`finalRound`는 건너뛰지 않는다 |
| 입력 | 화면 아무 곳 탭 = `document` **capture 단계 `click`**(비트를 시작한 ✅ 탭은 건너뛰기가 되지 않음, RESEARCH Pitfall 3). 노트북: `Escape` 키도 건너뛴다 **[auto]** — 마우스 없이 진행하는 강사용 |
| 제외 대상 | `data-skip-ignore` 속성이 있는 요소 안의 탭은 건너뛰기로 보지 않는다: **🔊/🔇 토글**, **지금 끝내기**, **ConfirmDialog**, **시상식 `🔁 다시 하기`/`처음으로`** **[auto]** — 소리만 끄려는 탭이 축하를 끊으면 안 되고, 시상식 버튼은 그 자체로 동작해야 한다 |
| 건너뛴 결과 | 같은 프레임에 컨페티·버스트·링·흔들림 정리, DOM 별 제거, 배너 제거, 진행 중 소리 60ms 페이드아웃, 남은 예약 소리 취소. 점수판은 즉시 최종값 + 기존 pop. 캐릭터는 그 자세에서 REST로 감쇠(Phase 7) |
| 진행 잠금 | 건너뛴 직후 **250ms** 동안 모든 진행 버튼(`다음 ➡️`, `🔁 한 번 더 하기`, `🏆 결과 보기`, `🎲`)이 입력을 무시한다(공유 잠금 `lockInputFor(250)`). **보이는 비활성 표시는 없다**(버튼은 평소대로 160ms fade-in으로 나타나고, 250ms 안의 탭만 무시) |
| 시상식 등장 건너뛰기 | 진행 잠금을 **걸지 않는다**(등장 뒤에 새로 나타나는 버튼이 없고, 버튼은 처음부터 보임) |
| 보이는 힌트 | **게임 화면에는 없다** **[auto]** — 2.2초짜리 축하 위에 글자를 얹으면 아이의 시선이 갈라지고 "텍스트 최소화" 원칙과 충돌한다. 강사용 안내는 설정 탭 효과음 그룹의 힌트 한 줄로 둔다(§F8). 발견하기 어려운지 UAT에서 확인한다 |

## Interaction & Accessibility

- **3D는 장식, DOM이 진실(유지):** 성공(배너 + 점수판 + 판정 결과 줄), 실패(soft 배너 + 결과 줄·재도전 카드), 우승·별·배지(시상식 DOM 카드)는 모두 DOM 글자로 있다. 3D 시상대·컨페티·별 비행이 유일한 정보 수단인 경우는 없다.
- **색만으로 구분하지 않는다:** 우승자 = 🏆 + 금색 카드 + 단 위 위치 + 왕관 + 우승 줄 글자. 소리 상태 = 이모지 모양 + aria 라벨. 배지 = 이모지 + 이름.
- **live 영역:** 배너 `role="status"`(기존), 시상식 우승 줄 `role="status"`. 별 비행·효과는 `aria-hidden`.
- **포커스:** 단계가 바뀔 때 포커스를 옮기지 않는다(Phase 6 원칙, 시상식 포함). 키보드 Tab 순서 = 소리 토글 → (패널) → `🔁 다시 하기` → `처음으로`. 모든 새 버튼에 `:focus-visible` 3px `--sky`.
- **연타·새는 탭:** 건너뛰기 직후 250ms 진행 잠금(§F5) + 기존 400ms 판정 잠금 + 버튼 숨김(HUD-03) + 엔진 phase 가드.
- **대비:** 새 바탕(soft 배너 ≈ `#E2E7FF`, 우승 카드 ≈ `#FFF4D1`) 위 `--ink` 글자는 9:1 이상이다. `--ink-soft` 끝난 이유 줄은 Body 800(큰 굵은 글자 기준 3:1 이상, Phase 6과 같은 사용).
- **움직임 안전:** 화면 흔들림은 ⭐3에서만 320ms·6px 이하이고 reduced motion에서 꺼진다. 깜빡이는 섬광(초당 3회 이상 번쩍임)은 없다.
- **소리 안전(아동 청력):** 고정 중간 음량 + 리미터, 버튼 클릭음 없음, 늘 보이는 끄기 토글.
- **입력 보안:** 이름은 JSX 텍스트로만 렌더한다. CSS 변수에는 계산한 숫자만 넣는다. `dangerouslySetInnerHTML`·drei `Html` 금지.
- **오프라인·IP:** 별 SVG·효과·소리 모두 코드로 만든 오리지널이다. 외부 URL·파일·글꼴 없음(소스 가드 (a)(b)(c) 유지).
- **반응형 기준점(유지):** `max-width: 560px`, `orientation: landscape and min-aspect-ratio: 5/4`, `max-height: 760px`, 폰 가로 `max-height: 500px`.
